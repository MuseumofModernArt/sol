This is a simple [Parcel App](https://parceljs.org/getting-started/webapp/) to showcase how to use [Sol](https://github.com/MuseumofModernArt/sol/) CSS framework. The [wiki](https://github.com/MuseumofModernArt/sol/wiki) describes the nomenclature and how CSS properties are mapped, but does not provide examples. The intention of this repo is to provide examples.

```
# Install dependencies
yarn install

# Run dev/hrm server and serve all files under src/
yarn parcel src/index.html
```
